# Your private CV workspace

The starter is fictional Alex Example content. Replace the evidence profile
and edit the two QMD files before sharing anything. From this directory use
cv-buid build, or cv-buid build --watch (Ctrl+C to stop). Outputs are in
private/quarto/output/. Quarto and TinyTeX with the documented TeX packages are
required; nothing is installed automatically. PDF uses TeX's Helvetica-compatible
sans-serif family; Word explicitly uses Arial. Fonts are not bundled, and Word
pagination may differ. Keep this repository private. AGENTS.md is yours to edit.
